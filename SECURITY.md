# Security & Disclosure Policy

SuusStudio™ keeps production credentials, client information and proprietary implementation details out of this public showcase.

## Please do not submit

- credentials or API keys
- private client information
- personal data
- confidential project files

If you believe you have found a security issue relating to a SuusStudio public project, use the contact route published on the official SuusStudio website rather than opening a public issue containing sensitive details.
