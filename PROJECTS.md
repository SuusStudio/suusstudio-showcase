# SuusStudio™ Systems & Projects Portfolio

This is a public, presentation-safe catalogue of systems, prototypes, frameworks and experiments developed under SuusStudio™.

The catalogue intentionally describes **what was built, why it exists, and its maturity** without publishing proprietary prompts, private source code, credentials, client data or protected commercial logic.

## Maturity labels

- **PUBLIC** — public-facing page, demo or showcase is available.
- **VERIFIED PROTOTYPE** — a working prototype has been built and tested in its intended technical scope.
- **BUILT PROTOTYPE** — implementation exists, but it is not presented as production infrastructure.
- **PRIVATE SYSTEM** — actively developed or used internally; implementation remains private.
- **TECHNICAL DEMO** — proves a specific technical or product concept.
- **SPEC / RESEARCH** — architecture, rules, tests or design are documented, while implementation is partial or intentionally not public.
- **EXPERIMENTAL / FAILED TEST** — preserved because failed experiments are part of the engineering record and inform later versions.

# What remains private

The following are deliberately **not** published in this showcase:

- proprietary system prompts and orchestration logic
- private repositories and production source code
- identity reference assets or biometric-style source material
- API keys, secrets and credentials
- private client work and client data
- internal sales data and payment information
- protected commercial implementation details

A public portfolio should prove capability without giving away the engine.
