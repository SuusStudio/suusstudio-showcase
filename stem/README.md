# SuusStudio™ STEM Showcase | Preview V0.1

## Gebruik
Open `index.html` in een moderne browser. Alle media en scripts zitten in deze map. Geen server, installatie, tracking of netwerk nodig.

## Afbeelding
`assets/stem-concept-hero.jpg` is de speciaal gegenereerde futuristische showcaseafbeelding. Zij is **conceptkunst**, niet een echte meting of screenshot van een model. De HTML-pagina toont daarom de verifieerbare resultaten afzonderlijk.

## Interactief
Het Vision-tabblad is een **geprogrammeerde uitlegillustratie**, geen echte AI-modelinference. Buttons voor bekend, onbekend en zwak beeld wijzigen alleen de simulatie.
