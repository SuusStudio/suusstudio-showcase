# SuusStudio™ STEM | Public Research Showcase

This folder contains the original visual concept artwork, a polished STEM overview, and a deliberately illustrative interactive example. The example is NOT connected to live models or private software.

## What we show
- High-level research themes and demonstrable capabilities.
- Limited aggregate internal research outcomes, explicitly scoped.
- Clear separation between research, simulations and future directions.

## What stays private
Core software, algorithms, architecture, model choices and routing, prompts, evaluation rules, thresholds, dataset composition, internal audit evidence, configuration, credentials, infrastructure and commercial plans.

No private source files, model weights, customer information, personal recordings, raw study data or internal evidence bundles belong in this public repository.

The hero artwork is fictional and contains illustrative UI. The public HTML/CSS/JavaScript only implements a presentation. Public descriptions are NOT independent certification, a production claim or proof of AGI.

The live SuusStudio website is separate; GitHub source being public does not demonstrate a deployment.

**Publication caution:** Git history and external caches may retain earlier versions of material even after edits.
